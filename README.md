## 💻 Sobre

O **Feedback Flow** é uma solução completa desenvolvida para centralizar a coleta de opiniões e sugestões. O sistema permite que administradores gerenciem múltiplos projetos, visualizem métricas em tempo real e recebam feedbacks através de uma API pública.

Projeto desenvolvido como parte do portfólio de **Engenharia da Computação** na **UNIVASF**.

### ✨ Funcionalidades Principais

- [x] **🔐 Autenticação JWT**: Login seguro e proteção de rotas.
- [x] **📊 Dashboard Interativo**: Visualização de métricas (Total vs Recentes).
- [x] **🚀 Gestão de Projetos**: Criação de múltiplos espaços para feedback.
- [x] **💬 Feed em Tempo Real**: Listagem dinâmica das mensagens recebidas.
- [x] **🎨 Dark Mode**: Interface moderna e responsiva.
